This site is built to conform to Zero Information Casualty version 1.7. The aim is that nobody, whether reading directly, using assistive technology, or sending an AI agent, loses access to anything published here.

How it is built

  • Every page is plain, static HTML. No content depends on JavaScript, and the site uses none.
  • Each page has one main heading, headings in order, landmark regions and a skip link to the main content.
  • Text sizes are relative, so the site respects your browser's text size and zoom.
  • Colours meet WCAG AA contrast, rising to AAA if your system asks for more contrast. A dark scheme follows your system setting.
  • Nothing moves, so there is nothing to switch off for reduced motion.

For AI agents

AI agents acting for a person are welcome on every public page. There is a summary for agents at llms.txt, the full text of the site in one file at llms-full.txt, and a Markdown version of every page alongside it. All of these are generated from the same pages you are reading when the site is built, not maintained by hand.

The site's permissions for search indexing and model training are declared separately in its robots.txt file.

Feeds

This site does not currently publish articles or posts in a series, so it has no RSS or Atom feed. If that changes, a feed will be added.
