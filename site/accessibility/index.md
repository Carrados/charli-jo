# Accessibility statement

Canonical page: https://charli-jo.com/accessibility/

This site is built to conform to [Zero Information Casualty version 1.7](https://zeroinformationcasualty.org/). The aim is that nobody, whether reading directly, using assistive technology, or sending an agent, loses access to anything published here.

## How it is built

- Every page is plain, static HTML. No content depends on JavaScript, and the site uses none.
- Each page has one main heading, headings in order, landmark regions and a skip link to the main content.
- Text sizes are relative, so the site respects your browser's text size and zoom.
- Colours meet WCAG AA contrast, rising to AAA if your system asks for more contrast. A dark scheme follows your system setting.
- Nothing moves, so there is nothing to switch off for reduced motion.

## Standards and testing

The site aims to meet WCAG 2.2 at level AA as a baseline, alongside Zero Information Casualty v1.7. It has been checked with WAVE, and I test it myself with screen readers and with agents as it changes.

This is a statement of how the site is built and what it aims for, not a claim of certified conformance. No independent audit has been carried out. The two Word documents offered for download are provided for convenience; the web pages are the accessible versions.

This statement was last reviewed on 30 October 2026.

## For agents

Agents acting for a person are welcome on every public page. There is a summary for agents at [llms.txt](/llms.txt), the full text of the site in one file at [llms-full.txt](/llms-full.txt), and a Markdown version of every page alongside it. All of these are generated from the same pages you are reading when the site is built, not maintained by hand.

The site's permissions for search indexing and model training are declared separately in its [robots.txt file](/robots.txt).

## Feeds

This site does not currently publish articles or posts in a series, so it has no RSS or Atom feed. If that changes, a feed will be added.

## If something does not work

Please tell me at <hello@charli.io>. I test this site with screen readers and with agents, but I would rather hear about a barrier than assume there is none.
